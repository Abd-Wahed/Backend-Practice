# Backend Practice: Simple CRUD Application

A full-stack project demonstrating basic Create, Read, Update, and Delete (CRUD) operations. This repository contains both the client-side user interface and the server-side REST API.

## 📁 Repository Structure

This repository is organized into two main directories:

* **`simple-crud-client`**: The frontend user interface built to interact with the backend API.
* **`simple-server`**: The backend REST API built to handle data processing and database operations.

## 🚀 Getting Started

To run this application locally, you will need to start both the server and the client concurrently.

### 1. Backend Setup (`simple-server`)

Navigate to the server directory, install dependencies, and start the backend server:

```bash
cd simple-server
npm install
npm run dev
